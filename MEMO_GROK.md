# Grok Evaluation For Memo

Grok is not a default Memo worker. It may later be evaluated as an optional,
user-approved specialist for X-native research, image understanding, or an
independent second opinion.

Adopt it only after a bounded agent with no edit, shell, or delegation powers
beats Memo on held-out tasks at acceptable cost and latency. Sol remains the
final author and adjudicator. Do not adopt any provider based on a single demo.
